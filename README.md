# Mantra Japa Tracker

Mantra Japa Tracker is an Android application that helps you track your mantra japas. It allows you to input the mantra you are chanting, track how many malas of that mantra you have completed, and tag each mantra to a deity. The app also allows you to set targets for your mantra chanting.

## Features

*   Track mantra japas and malas
*   Associate mantras with deities
*   Set targets for mantra chanting
*   View statistics of your progress

## Getting Started

To build and run the app, you can open the project in Android Studio and run it on an emulator or a physical device.

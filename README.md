# Mantra Japa Tracker

Mantra Japa Tracker is a modern Android application designed to help you focus on your spiritual practice. It provides a simple and intuitive interface to track your mantra japas, organize them by deity, and view detailed statistics of your progress.

## Features

*   **Add Deities:** Create a personalized list of deities for your practice.
*   **Add Mantras:** For each deity, add the specific mantras you chant.
*   **Japa Counter:** A simple and clean interface to count your malas for each mantra.
*   **Increment/Decrement:** Easily correct your count with both increment and decrement buttons.
*   **Save Progress:** Save your japa sessions to keep a complete history.
*   **Statistics:** View detailed statistics for each mantra and each deity, including total malas and total japas.
*   **Modern UI:** A clean and calming user interface built with Jetpack Compose.
*   **Persistent Storage:** Your data is saved locally on your device using a Room database.

## Tech Stack

*   **Kotlin:** The official language for Android development.
*   **Jetpack Compose:** Android's modern toolkit for building native UI.
*   **Room:** A persistence library that provides an abstraction layer over SQLite.
*   **ViewModel:** Manages UI-related data in a lifecycle-conscious way.
*   **Coroutines:** For asynchronous programming.
*   **Material Design 3:** For a modern and visually appealing design.

## Getting Started

To build and run the app, open the project in Android Studio and run it on an emulator or a physical device.
